# Mix — Implementation Plan

1. Add `src/app/mix-schema.ts` as an independent `defineToolcraft` product contract. Reuse Speed Rays' built-in source-mask, ray, gradient, motion, background, image-export, and video-export sections; insert a Blur section with Speed Blur's Motion, Exposure, Focus area, and Blend sliders; enable editable raster render scale and the six-second playback timeline; expose only Export Video, Export PNG, and Copy PNG sticky actions.
2. Add narrow reusable exports in `src/app/clip-lab-renderer.tsx` for the accepted source decode, threshold mask, clipped segment model, timeline motion model, Canvas 2D ray-frame replay, and common timestamped video helpers. Do not change `/clip-lab` defaults, SVG preview, output, or delivery behavior.
3. Generalize the internal WebGL source upload in `src/app/warp-renderer.tsx` so the accepted radial exposure renderer can consume either an image or an already-rendered canvas with explicit source dimensions. Preserve `/warp` shader behavior, defaults, intrinsic-media behavior, focus handle, and still export.
4. Add `src/app/mix-renderer.tsx` with a cached two-stage pipeline: derive Speed Rays geometry from the invisible mask, rasterize the current ray/timeline frame into a bounded live-preview canvas, then upload it to the shared full-backing WebGL radial exposure pass. Bind the panel and textless canvas handle to the shared `clip.focus`. Replay both passes at exact selected dimensions for current-frame PNG/JPG, PNG clipboard copy, and deterministic MP4/WebM export with progress.
5. Add `src/routes/mix.tsx` as a thin `ToolcraftApp` composition. Route easing preset actions through runtime commands and route delivery actions to the Mix renderer helpers. Register `/mix` in `src/routes/root.tsx` and add the Mix launcher entry in `src/routes/index.tsx` without changing the two source routes.
6. Add `src/app/mix-acceptance.ts`, `src/app/mix-performance.ts`, and `src/app/mix-schema.test.ts`. Cover every visible Mix control, shared focus handle, playback timeline, raster-only action set, source lifecycle, renderer stages, current-frame capture, video delivery, workload controls, render scale, and viewport interactions.
7. Add `e2e/mix.spec.ts` and update dashboard/clipboard browser coverage. Verify real upload and clear, Speed Rays geometry controls, all four Blur controls, shared focus, timeline play/scrub, absence of SVG actions, current-frame PNG/copy output, video export progress/bytes, render-scale backing pixels, and dashboard routing.
8. Update `docs/dashboard-spec.md` and `docs/toolcraft/agent-worklog.md` with the Mix decision trail, renderer/timeline/layers/controls/export/performance evidence, explicit source-tool references, state/output mapping, risks, and verification results.
9. Run `npm run typecheck`, focused Mix unit tests, `npm run verify:quick`, focused Chromium `/mix` acceptance, targeted Mix workload/playback/viewport/export performance checks, `npm run verify:final`, the required browser performance checkpoint, and `npm run dev`; finish with a real-browser visual inspection of `/mix`.
